Early means honest.

The native alpha runs the Reflex language core today. Web tooling, desktop packaging, and bridges are still moving from the reference prototype into the standalone runtime. The downloads page only links to installers that have actually been built and tested. Public releases should mirror these files in GitHub Releases, which becomes the permanent download source.
