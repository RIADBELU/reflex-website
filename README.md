# Reflex website

A dependency-free, responsive landing page for Reflex. The design intentionally avoids generic startup-language claims: it uses plain language, shows the actual command-line workflow, and clearly separates what works from what is still in progress.

## Preview locally

```bash
cd website
python -m http.server 4173
```

Then open `http://localhost:4173`.

The production site is static and can be deployed to GitHub Pages, Netlify, Cloudflare Pages, Vercel, or any standard web host. Replace the placeholder section links with official GitHub, documentation, and download URLs when those exist.
